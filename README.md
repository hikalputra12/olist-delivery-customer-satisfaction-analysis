# Olist Delivery & Customer Satisfaction Analysis

## Project Status
In progress — business understanding and project planning.

## Overview
This project analyzes delivery performance and customer review
scores using the Brazilian E-Commerce Public Dataset by Olist.

The goal is to identify operational areas that may need attention
based on delivery delays, order volume, and customer feedback.

## Business Scenario
This portfolio project adopts the perspective of a marketplace
operations analyst supporting delivery performance improvements.

## Business Questions
1. How does delivery performance change over time?
2. Which customer regions and product categories have the highest
   late delivery rates?
3. How do customer review scores differ between on-time and
   late deliveries?
4. Which segments should be prioritized for further investigation
   based on order volume, delivery delays, and review scores?

## Planned Tools
- PostgreSQL: data validation, cleaning, and analysis
- Power BI: interactive dashboard
- GitHub: documentation and version control

## Dataset
Brazilian E-Commerce Public Dataset by Olist:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Methodology
Ask → Prepare → Process → Analyze → Share → Act

## Important Notes
- Customer review scores are used as an indicator of satisfaction,
  rather than a dedicated CSAT survey.
- The analysis explores associations and does not establish causation.
- Recommendations will be based on findings; business impact has
  not been tested.

## Planned Deliverables
- Documented SQL scripts
- Interactive Power BI dashboard
- Summary of findings and recommendations
